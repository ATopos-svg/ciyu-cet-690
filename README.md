# 词屿 · 690 词复习

为手机、iPad 和电脑制作的个人英语六级词汇复习应用。无需安装依赖，无需后端。

## 使用

1. 在 Safari 或 Chrome 打开网页地址。iPhone / iPad 可通过“分享 → 添加到主屏幕”安装。
2. 看英文、回想中文，轻触卡片或“点击揭晓释义”。默认自动播放英文读音，可在设置里调整。
3. 释义、构词提示、同根词与派生词一起出现；点击派生词可听发音。
4. 选择“没想起来 / 有点模糊 / 记住了”，保存复习进度并安排下一次复习。
5. 在设置里点击“下载离线发音”，等待 690 / 690 完成。首次联网打开并完成下载后，词库与词册内音频可离线使用。

进度保存在当前浏览器设备上。在“足迹”里导出 JSON 备份，传到另一台设备后导入即可。当前版本没有自动跨设备同步。清除浏览器数据会清除本地进度，请定期备份。

## 词库

- `六级词汇340_黑白打印版.pdf`：340 个词。
- `最新已背350词_黑白搭配速记表.pdf`：350 个词。
- 总计 690 个词，无重复。
- 第一份文件中的 `legat` 根据释义纠正为 `legal`，页面保留纠正标记。
- 第一份文件中截断的释义已补全；机械生成、不自然的搭配未作为推荐搭配展示。
- 点击卡片中的“查看原始 PDF 出处”可查看源文件名、页码、词条号与原始释义。
- 构词提示区分历史词源、现代词基与复合词；不可可靠拆解的单词按整体记忆。此类提示用于辅助记忆，并非所有单词都能由词根准确推导词义。
- 690 个词册内音频为有道词典美式发音。词册外的派生词使用设备英文语音，需设备安装可用英文语音。用于个人学习。

切换到待巩固、到期复习或另一词册再返回，会接着原来的未完成单词继续。查看词库单词不会覆盖复习队列。

## 间隔复习

- 没想起来：加入待巩固，满 10 分钟后进入到期复习，计时按真实时间计算；也可在待巩固列表主动提前练习。
- 有点模糊：加入待巩固，下次到期时间为 1 天后。
- 记住了：按 3、7、14、30、60 天递增；只在到期后再次记住才延长间隔。
- 今日词数按不同词条去重计算。只浏览或揭晓，不会计入完成数。

## 部署

该目录是完整静态网站。上传目录中的全部文件（包含 `audio` 子目录）到 GitHub Pages、Cloudflare Pages 或任一 HTTPS 静态网站即可。必须保留相对路径。

使用 GitHub Pages 时，在仓库 Settings → Pages 里选择 `main` 分支、根目录 `/`。代码与词库会在仓库中公开可见。

本地预览可运行：

```sh
python -m http.server 8765 --directory .
```

然后打开 `http://localhost:8765`。直接双击 HTML 可查看页面，但主屏幕安装与离线缓存需要 HTTPS 或 localhost。
